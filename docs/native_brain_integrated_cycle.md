# Native Brain Integrated Cognitive Cycle

The integrated cognitive cycle joins Velvet's bounded local cognition layers into one finite, deterministic heartbeat.

```text
Orient Self
→ Check Keys
→ Observe
→ Presence
→ Attention
→ Curiosity
→ Judgment
→ Pattern
→ Expectation
→ Intent
→ Choose bounded outcome
→ Rest
```

The cycle is not an agent loop. It runs once, records a trace, returns a result, and goes back to rest. It does not internally retry, poll hardware, call a model, write memory, dispatch work, or keep itself alive.

## Foundation law

> Cognition may mature through the ladder. Authority does not travel with it.

Every integrated result remains:

```text
canonical: false
speaking_authorized: false
memory_write_authorized: false
runtime_placement_authorized: false
court_authorized: false
execution_authorized: false
actuation_authorized: false
authority: none
rested: true
```

## Required keys

A heartbeat proceeds only when all five cognitive keys are satisfied:

- constitutional identity is Velvet;
- Riven continuity is verified;
- Runtime context is verified;
- a bounded observation exists;
- the No Drift integrity gate is aligned.

A missing key produces a held result and immediate rest. No downstream cognitive stage is forced to run.

## Presence before expression

Presence is evaluated near the beginning of the heartbeat. It determines whether the moment is suitable for speech, waiting, questioning, or safety escalation.

Presence does not make an intent speak. It supplies timing context to later review. Speech-shaped intent candidates still report `speaking_authorized: false`.

## Safety owns the interruption path

Safety may take ownership from Presence, Attention, Curiosity, Judgment, Pattern, Expectation, or Intent.

When safety owns the next decision:

1. the normal cognitive ladder stops;
2. the trace records the exact stage and reason;
3. the result reports `safety_deferred: true`;
4. no ordinary proposal continues downstream;
5. the heartbeat returns to rest.

The integrated cycle does not perform emergency action. It hands the decision boundary to the existing safety, Court, Runtime, and executor paths.

## Quiet cognition is a complete outcome

A heartbeat is successful even when it produces no question, claim, pattern, expectation, or intent.

`quiet_observation` means the observation was processed without forcing certainty or entering the moment. This is not failure and does not require another immediate cycle.

## Outcome precedence

The result reports the highest bounded cognitive product reached:

```text
intent candidate
expectation candidate
pattern candidate
judgment ready
question candidate
quiet observation
```

A higher product does not erase the earlier assessments. The full trace and intermediate objects remain available for inspection.

## Context alignment

The cycle derives shared integrity, continuity, Runtime, Presence, and safety boundaries from verified cycle inputs. Domain context may be stricter, but it cannot weaken the verified foundation gates.

For example:

- a domain Judgment context may block itself even when the whole-body keys are valid;
- an Intent context cannot claim speech is allowed when Presence says the moment belongs to silence;
- a simulated observation cannot mature through Pattern into a real-world Expectation.

## Distributed body boundary

The integrated cycle ends at a proposal-only Intent candidate.

For work-shaped proposals:

```text
Native Brain describes the objective and constraints.
Runtime chooses and leases a suitable organ.
Event Protocol carries the state.
Court authorizes consequential work.
The selected organ performs its bounded contract.
Receipts preserve what happened.
Riven preserves only durable body change.
```

The Queen retains whole-system awareness and final coordination, but the integrated heartbeat does not assume that the Queen performs the work.

## Determinism and trace

Identical inputs produce identical:

- key states;
- Presence decision;
- cognitive assessments;
- final bounded outcome;
- stage trace.

The trace always ends with `rest`.

## Current boundary

This layer adds local deterministic orchestration only. It adds no scheduler, Event Protocol publication, network listener, model call, canonical memory write, workload lease, Court decision, executor, CAN transmission, actuator path, or physical authority.

Current physical authority remains none.
