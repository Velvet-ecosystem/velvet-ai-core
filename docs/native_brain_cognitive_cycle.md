# Native Brain Cognitive Cycle

The cognitive cycle is one bounded, deterministic heartbeat. It begins with Self Orientation, checks the required keys, accepts one read-only observation, evaluates Presence, chooses one cognitive outcome, and returns to Rest.

```text
orient self
  -> check cognitive keys
  -> observe
  -> presence
  -> choose
  -> rest
```

## Cognitive keys

The first cycle requires five keys:

- identity: the constitutional Self reference is Velvet;
- continuity: Riven continuity is verified;
- context: Runtime active context is verified;
- observation: one bounded read-only observation is available;
- integrity: the No Drift gate is aligned.

A missing key does not create an error-shaped performance. The cycle chooses Wait or Silence, records the missing key, and returns to Rest.

These keys are readiness facts, not cryptographic secrets, capabilities, Court grants, or execution permissions.

## Every cycle ends

Native Brain does not run an unbounded private monologue. One invocation produces one decision and one trace. Further thought must be represented by a future observation, an Open Thread, or a Deferred Thought.

Rest means the cycle has returned to a calm baseline. It does not erase working state and does not imply sleep, shutdown, or lost awareness.

## Trace

The trace records each stage and its reason. It is intended for debugging, replay, explanation, and later learning research. It is not a canonical receipt and does not replace Receipts.

## Authority boundary

A completed cycle always reports authority as `none`.

Safety-relevant Presence may produce `escalate` and permit an interruption, but escalation remains a data outcome. Runtime and Court remain the only route toward consequential action.

## Determinism

With the same Self Orientation, observation, and Presence context, the first implementation returns the same keys, decision, and trace. No model, cloud service, learned weight, token machine, or adaptive rule participates in this layer.
