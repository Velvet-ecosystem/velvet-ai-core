# Native Brain Self and No Drift

## Purpose

Native Brain requires a stable point of reference before it interprets the world.

Self Orientation answers:

> Who am I in this cognitive cycle, and am I still aligned with the Velvet body I was enrolled to serve?

It does not claim consciousness, prove identity, or replace continuity verification.

## Responsibility boundary

- Riven preserves and verifies lineage through time.
- Runtime supplies the active verified body, profile, session, and surface context.
- Native Brain forms a bounded orientation for the current cognitive cycle.
- Personality supplies slow-changing expression tendencies.
- Preferences supply fluid learned tendencies.
- Models may help express Self but may not define or rewrite it.

## Layer separation

```text
identity     nearly immutable constitutional reference
personality  slowly and deliberately revised expression profile
preferences  fluid learned tendencies
mood         temporary state outside constitutional identity
context      current verified body, session, surface, and environment
```

A preference change is not identity drift. A temporary mood is not personality replacement. A fluent model statement is not Self.

## Cycle orientation

A future complete cycle should follow:

```text
wake
  -> receive verified Riven and Runtime context
  -> orient Self
  -> evaluate No Drift integrity
  -> observe
  -> presence judgment
  -> reason
  -> choose bounded cognitive outcome
  -> rest
```

If continuity or active Runtime context is not verified, the orientation remains degraded and cannot be treated as ready for normal reasoning.

## No Drift law

> Learning may improve Velvet. Learning may never replace Velvet.

The Integrity Gate compares the current constitutional identity reference with an enrolled baseline. It detects changes in name, body model, owner relationship, mission, or principles and reports them as drift.

The fingerprint used by the current implementation is only a deterministic comparison digest. It is not a signature, Riven proof, Court grant, or security boundary.

## Growth without drift

Learning may alter:

- attention;
- timing;
- confidence;
- interpretation;
- preferences;
- deliberately versioned personality traits.

Learning may not silently alter:

- constitutional identity;
- mission;
- proposal-only authority posture;
- Unified-Organ body membership;
- the owner relationship;
- foundational principles.

Changes to constitutional identity require an explicit governed migration with Riven and Runtime evidence. Native Brain cannot approve that migration itself.

## Authority posture

Self Orientation carries no execution authority.

Knowing "I am Velvet" does not permit action. Remembering an owner preference does not create a capability. Passing the No Drift gate does not grant Court approval.

The orientation summary therefore always reports authority as `none`.
