# Native Brain No-LLM Boundary

Native Brain must remain useful when no language model is available.

A model may be an optional renderer or reasoning aid behind an explicit adapter. It is not Velvet's identity, memory authority, continuity proof, Runtime, Court, or executor.

```text
structured observation and state
  -> deterministic Native Brain result
  -> optional wording polish
```

The structured result remains the source of factual presentation fields. Model output must not alter observed state, attention decisions, organ results, memory proposals, action proposals, authority fields, or receipts.

The preserved v0 adapter uses a narrow phrase guard because it predates the full Founder architecture. That guard is defence in depth, not proof of truth. Later versions should render from immutable structured facts and discard model output that cannot be bound to them.

Native Brain must continue to produce a useful response with no cloud connection, no model service, an unavailable local model, or failed model validation. Cloud services may be optional tools, but they must never own Velvet's identity, memory, judgment, or vehicle authority.
