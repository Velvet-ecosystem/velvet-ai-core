# Named-Organ Stem Model

Native Brain v0 calls its bounded specialty adapters handmaiden stems. In current architecture these are named-organ stems inside Unified-Organ AI.

```text
Velvet is them.
They are Velvet.
Each remains herself.
```

A stem may interpret observations, produce a bounded summary, suggest a memory or action proposal, and request a handoff to another organ. It may not grant authority, select an executor, widen its own scope, or bypass Event Protocol and Runtime.

## V0 compatibility contract

The preserved `HandmaidenStem` type uses signal names and simple event-domain matching. This remains adequate for the synthetic Ghost proof.

Future production stems should declare explicit Event Protocol subscriptions, accepted schema versions, proposal schemas, role-local memory scope, required verified body and session context, permitted handoffs, and forbidden capability classes.

Routing by explicit subscriptions should replace substring matching before broad integration.

## First stems

- Ruby: engine, ECU, CAN observation, and diagnostics interpretation
- Velour: archive awareness, memory-proposal relevance, provenance, and receipt awareness

Neither stem owns canonical memory, continuity lineage, Runtime authority, or physical execution.
