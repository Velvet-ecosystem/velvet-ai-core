# Velvet Native Brain v0

Velvet Native Brain v0 is a preserved experimental local-cognition scaffold for descriptive state, attention priority, bounded organ stems, memory proposals, and no-LLM response planning.

It is not a model, not an executor, not the canonical memory ledger, and not an authority lane.

```text
Velvet may use models, but she must not be made of them.
```

## Current repository role

Native Brain belongs inside `velvet-ai-core` as a brain-facing experimental subsystem. Core interprets and proposes. It does not replace the verified Founder Runtime, Event Protocol, Court, Receipts, or Riven.

The preserved v0 loop remains intentionally tied to the synthetic Ghost CAN fixture so its original proof stays reproducible. A later compatibility layer may accept verified observation envelopes from Event Protocol without changing the no-authority law.

## Responsibility

Native Brain v0 may validate a bounded observation fixture, update descriptive state, assign attention, route observations to bounded named-organ stems, create non-canonical memory proposals, produce a no-LLM response skeleton, and optionally ask a model to polish wording.

Native Brain v0 must not grant authority, select executors, create capability tokens, own canonical memory or continuity, create canonical receipts, touch hardware, run shell commands, perform medical or driving execution, or bypass Event Protocol, Runtime, Court, safety gates, executors, or Receipts.

## Preserved first loop

```text
synthetic Ghost CAN observation
  -> no-authority safety check
  -> descriptive state update
  -> brainstem priority
  -> Ruby diagnostic interpretation
  -> Velour archive-aware interpretation
  -> non-canonical memory proposal
  -> no-LLM response
```

## Ownership map

- `velvet-ai-core`: Native Brain abstractions, descriptive state, reasoning, and proposal structures
- `velvet-event-protocol`: typed observation and proposal transport
- `velvet-runtime`: verified context, route enforcement, coordination, and the sole write-capable path
- Court: protected-action authorization
- `velvet-receipts`: canonical consequential evidence
- `velvet-continuity-spine` / Riven: identity lineage and continuity integrity
- `velvet-persona-continuity`: bounded recall and persona context compilation

## Promotion status

This subsystem is restored as experimental code so its local-first design can be evolved safely. The Ghost-specific API remains a compatibility proof. General Event Protocol observation intake, explicit memory and action proposal contracts, subscription-based organ routing, and presentation-only model rendering belong in later focused changes.
